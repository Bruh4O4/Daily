# 📅 Daily — Персональный трекер привычек

**Daily** — это легковесное и отзывчивое веб-приложение для формирования полезных привычек. 

### 🎯 Суть проекта
Суть трекера заключается в том, что пользователь сам устанавливает цель по количеству дней для каждой задачи. Приложение помогает дисциплинированно фиксировать ежедневное выполнение и оставлять комментарии к каждому дню до тех пор, пока действие не дойдет до автоматизма — то есть пока пользователь полностью не достигнет своей цели по дням выполнения.

---

## ✨ Основные возможности

*   **Управление целями:** Добавление новых привычек с указанием целевого количества дней.
*   **Логирование с комментариями:** Возможность привязывать текстовые заметки и мысли к каждому успешному дню.
*   **Сохранение данных:** Интеграция с `LocalStorage` — ваш прогресс и история дней не сотрутся при обновлении страницы.

## 📂 Структура проекта

```text
Daily/
├── data/                 # Локальные демонстрационные данные
│   └── demo.json         # JSON-файл с начальными привычками
├── img/                  # Статические графические ресурсы
│   ├── Add.svg           # Иконка добавления новой привычки
│   ├── Star.svg          # Иконка активной/выполненной звезды
│   ├── Star_stroke.svg   # Иконка контура звезды (невыполненный день)
│   ├── cross.svg         # Иконка закрытия или отмены
│   └── delete.svg        # Иконка удаления элемента
├── script/               # Логика интерактивного интерфейса
│   └── index_app.js      # Основной JavaScript-модуль приложения
├── index.html            # Главная страница и HTML-разметка
├── index_style.css       # Таблица стилей для оформления трекера
└── README.md             # Документация проекта
```
